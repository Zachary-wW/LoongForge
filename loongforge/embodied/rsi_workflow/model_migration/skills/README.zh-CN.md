# Skills

模型迁移工作区的技能集目录。迁移过程中主要使用到的 skill（智能体技能）统一整理在这里，由 `core` 调度调用，避免能力散落在各处。

## 职责

- 集中管理迁移流程依赖的技能，作为 `core` 的能力来源。
- 每个 skill 封装一类可复用的操作能力（如代码生成、格式转换、命令执行、检查修复等），供调度流程按需调用。
- 保持技能与 `core` 解耦：新增能力时只需在 `skills` 中补充对应 skill，`core` 无需改动。

## 目录内容

- 技能定义：每个子目录或文件对应一个 skill，包含其能力说明、接口与使用约束。
- 技能清单：说明各 skill 的用途与适用场景，便于调度时选择。
