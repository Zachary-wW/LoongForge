# Docs

The documentation directory of the model-migration workspace. It holds usage guides and samples for the features, helping users understand the RSI migration workflow, get started with the functionality provided by `core`, and write/submit migration outputs following the conventions.

## Responsibilities

- Records how to use each functional module (sandbox, templates, scheduling, validation, etc.).
- Provides operation samples to lower the learning curve.
- Captures conventions and best practices of the migration process to keep the whole workspace consistent.

## Contents

- Feature guides: interfaces, parameters, and usage notes for each module.
- Samples: worked examples and expected outputs for common scenarios.
- Conventions: directory structure, naming rules, and the submission/validation flow.
